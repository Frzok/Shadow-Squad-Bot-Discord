# Запросы на данные: памятка оператору

Это рабочий порядок для запросов на просмотр, исправление или удаление данных
участника.

## Просмотр и исправление

1. Принять запрос в личных сообщениях `@frzok` или по адресу
   `morksid.m@gmail.com`.
2. Уточнить Discord ID. Пароль, Discord-токен и данные входа Battle.net для
   проверки не нужны.
3. Найти записи этого ID в рабочей SQLite. Данные других участников в ответ
   не включать.
4. Простые исправления сделать командами бота. Для прямого изменения SQLite
   сначала остановить службу.
5. Записать дату выполнения запроса без лишних подробностей.

## Удаление

1. Остановить бота.
2. Убрать привязки участника из `DISCORD_CHARACTER_LINKS`, если они заданы в
   `.env`.
3. При отказе от развлекательного выбора добавить Discord ID в
   `PIDOR_EXCLUDED_USER_IDS`.
4. По возможности удалить сообщения бота, на которые распространяется
   запрос.
5. Запустить очистку рабочей базы и локальных копий:

```powershell
.\.venv\Scripts\python.exe deploy\purge_member_data.py `
  --member-id 123456789012345678 `
  --character CharacterName `
  --confirm DELETE-123456789012345678
```

`--character` можно повторить для нескольких персонажей. Если привязка ещё
есть в базе, скрипт сам добавит найденные имена в очистку.

Скрипт не делает страховочную копию: такая копия снова сохранила бы данные,
которые попросили удалить.

6. Проверить отчёт скрипта и `PRAGMA quick_check`.
7. Запустить бота.
8. Сообщить участнику о результате.

Если персонаж остаётся в составе Blizzard, не создавайте удалённую привязку
заново без согласования с участником.

Сообщения в Discord и данные Blizzard, WoW Audit или Warcraft Logs находятся
также у соответствующих сервисов. Бот может удалить только то, чем управляет
оператор Shadow Squad.
