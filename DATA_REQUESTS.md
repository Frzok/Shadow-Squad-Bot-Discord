# Обработка запросов на данные

Этот документ предназначен для оператора Shadow Squad Discord Bot. Он не
заменяет юридическую консультацию.

## Доступ или исправление

1. Получить запрос приватно через `@frzok` или `morksid.m@gmail.com`.
2. Подтвердить Discord ID заявителя. Не просить пароль, токен Discord или
   Battle.net.
3. Найти относящиеся к ID записи в рабочей SQLite-базе. Не отправлять заявителю
   данные других участников.
4. Исправить данные штатными командами, если это возможно, либо при
   остановленном Боте выполнить контролируемое изменение SQLite.
5. Зафиксировать дату исполнения без сохранения лишних персональных данных.

## Удаление

1. Остановить Бота, чтобы удалённые данные не появились снова из памяти.
2. Удалить привязки заявителя из `DISCORD_CHARACTER_LINKS` в `.env`, если они
   были настроены там. При отказе от развлекательного выбора добавить Discord
   ID в `PIDOR_EXCLUDED_USER_IDS`.
3. Удалить или исправить опубликованные Ботом Discord-сообщения, если запрос
   распространяется на них и у оператора есть такая возможность.
4. Запустить локальный инструмент очистки для рабочей базы и всех копий:

```powershell
.\.venv\Scripts\python.exe deploy\purge_member_data.py `
  --member-id 123456789012345678 `
  --character CharacterName `
  --confirm DELETE-123456789012345678
```

`--character` можно указать несколько раз. Если привязка ещё присутствует в
базе, инструмент сам найдёт её персонажей. Инструмент не создаёт страховочную
копию, поскольку такая копия сохранила бы удаляемые данные.

5. Проверить итоговый отчёт инструмента.
6. Если пользователь просил прекратить обработку данных персонажа Blizzard,
   не создавать привязку заново. Если персонаж всё ещё находится в составе,
   обсудить с пользователем и Blizzard применимый способ выполнения запроса до
   следующей синхронизации.
7. Запустить Бота и убедиться, что рабочая база проходит `PRAGMA quick_check`.
8. Сообщить пользователю об исполнении или о законной причине частичного
   отказа.

Отдельно учитывайте, что сообщения, уже опубликованные в Discord, управляются
Discord и правами соответствующих каналов, а данные Blizzard, WoW Audit и
Warcraft Logs — этими независимыми сервисами.
