# WR Cloud → Archon

Локальный импортёр записей Warcraft Recorder Cloud в библиотеку Archon App.

Он:

- получает доступные вашему аккаунту записи WR;
- сравнивает их с уже известными Archon боями;
- автоматически выбирает только уверенные совпадения по времени, encounter ID,
  результату и составу игроков;
- скачивает MP4 в папку `warcraft-live`;
- создаёт `metadata.json` с существующей привязкой `reportCode + fightId`;
- не заменяет и не удаляет существующие файлы.

## Запуск

1. Закройте Archon App или будьте готовы перезапустить его после импорта.
2. Дважды нажмите `start_importer.bat`.
3. Введите данные Warcraft Recorder Cloud и название гильдии WR.
4. Проверьте автоматически найденную папку Archon.
5. Нажмите «Проверить облако».
6. Выберите зелёные строки и нажмите «Импортировать выбранные». Если ничего не
   выбирать, будут импортированы все новые зелёные строки.
7. Перезапустите Archon.

Пароль не записывается импортёром на диск. Если на компьютере существует
`config-v3.json` Warcraft Recorder, поля могут быть заполнены из него при запуске.

## Ограничения первой версии

- Автоматически импортируются только записи, для которых Archon уже знает
  соответствующий серверный бой Warcraft Logs.
- Жёлтые неоднозначные совпадения намеренно не импортируются.
- Функция рассчитана прежде всего на рейдовые записи. Mythic+ сможет
  сопоставиться по времени и составу, если соответствующий бой уже находится в
  библиотеке Archon, но требует дополнительной проверки на реальных данных.
- WR и Archon используют неофициально совместимые форматы. После обновлений
  приложений импортёр может потребовать адаптации.
